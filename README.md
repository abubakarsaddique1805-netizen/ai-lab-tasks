# AI Labs 1–6 — Independent Practice Solutions

Organized using the six lab folders in the supplied reference repository. The Python implementations and explanations have been rewritten, while the required algorithms and task objectives remain the same.

- Lab1: AI history, scholarship screening, conversational test.
- Lab2: PEAS, environment classification, classroom controller.
- Lab3: BFS, DFS, DLS, IDDFS, UCS.
- Lab4: A*, UCS, heuristic overestimate.
- Lab5: minimax, alpha-beta, move ordering.
- Lab6: tokenization, TF-IDF chatbot, chunking, real embeddings, retrieval.

Run individual scripts from their lab directory, e.g. `cd Lab3 && python task1.py`.
For Lab6 install `pip install scikit-learn sentence-transformers transformers numpy` and run its scripts in Colab or a network-enabled Python environment. Pretrained MiniLM is downloaded from Hugging Face; no handcrafted embeddings are used.

Each report contains theory tasks and short explanations. All sample rules and policy documents are fictional. The package is for study and review; verify requirements and outputs before any submission.
